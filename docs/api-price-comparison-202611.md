## 这张表怎么读

- **官方价**：厂商公开的输入/输出单价，单位元 / 百万 tokens。
- **本站实付**：按当前最深一档卖家报价折算；同一模型有多个卖家档位。
- **折扣**：便宜 50% 是 5 折，便宜 99% 是 0.1 折；平台报价上限为官方价 5 折，最低 0.01 折。
- **卖家数**：当前挂单卖家数；调用前可在 [模型广场](https://ai.dijinlong.com/model-plaza) 看可用性。

## 为什么能便宜

LONG AI 不是单一上游转发加价：卖家把闲置模型额度挂出来自主报价，平台按报价、负载、健康度择优派单，故障自动切换。差价来自闲置额度转售、批量采购和区域定价，不是模型能力不同。当前平台抽成为 0（限时卖家扶持，截至 2026-12-31）。

## 常见问题

**0.1 折是不是每个人都能拿到？** 不是；这是当前最深一档报价，实际按可用档位、负载和路由结果计价。

**官方价和本站价差在哪？** 官方价是厂商公开定价；本站价是卖家报价供货后的实付价，平台负责撮合、调度与结算。

**只有一个卖家时会不稳定吗？** 多卖家会自动切换；单卖家建议留同类备用模型。接入见 [接入文档](https://ai.dijinlong.com/docs)。
